# 코드 스타일

- 기존 파일의 패턴과 ESLint·Prettier 설정을 우선한다. 새 스타일 규칙을 추측해 추가하지 않는다.
- TypeScript strict와 `@/*` 경로 별칭을 유지한다.
- UI·상태·계산 규칙·외부 조회의 책임을 구분한다. 서버 전용 정보를 클라이언트에 포함하지 않는다.
- 공통 UI는 `src/components/ui/`를 우선 활용한다.
- 사용자 문구는 한국어로 작성하고 실제 동작과 일치시킨다.
- 오류를 숨기는 `any`, 무차별적인 lint 비활성화, 작업과 무관한 포맷 변경을 피한다.
- 포맷은 변경 파일에 한정한다. 정확한 설정은 `.prettierrc.json`, `eslint.config.mjs`를 확인한다.
