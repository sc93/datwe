# 서비스와 데이터 정책

- DATWE(다음주 퇴사)는 개인 사이드프로젝트인 조건 선택형 로또 번호 생성 서비스다.
- GitHub 저장소: https://github.com/sc93/datwe

기능 기획·디자인·백로그와 작업 상태는 GitHub Issues에서만 관리한다. 이 문서에는 지속적으로 적용할 서비스·데이터 원칙만 기록한다.

## 데이터 정책

- `.env*`, 인증 정보, 토큰, 쿠키, 사용자 입력 원문을 커밋·로그·이슈·스크린샷에 노출하지 않는다. 필요한 설정은 값 대신 변수명으로 설명한다.
- 이름 원문과 생성 번호를 분석 이벤트에 전송하지 않는다. 이름 원문은 저장 기록에 남기지 않는다.
- 외부 응답은 신뢰하지 않고 회차, 날짜, 본번호·보너스의 범위·중복을 검증한다.
- 외부 조회 실패를 최신 데이터나 정상 조회로 표시하지 않는다. 일부 회차를 누락한 채 ‘최근 5회’ 조건을 적용하지 않는다.
- 서버리스 프로세스 메모리는 영속 저장소가 아니다. 캐시와 마지막 정상 데이터 보관을 구분한다.
- 로컬 저장·클립보드 실패를 성공으로 안내하지 않는다. 번호 생성 조건을 조용히 무시하지 않는다.
- 로또 당첨 가능성이 높아진다고 주장하지 않는다.
